## Теоретическая часть

| Концепция | Описание |
|---|---|
| Список смежности | Массив списков, где для каждой вершины хранятся её соседи. Занимает память **O(V + E)**, идеально подходит для разреженных графов. |
| DFS (Поиск в глубину) | Идёт по графу как можно глубже, пока не упрётся в тупик, затем возвращается. Реализуется рекурсивно или через стек. Сложность **O(V + E)**. |
| BFS (Поиск в ширину) | Исследует граф «слоями» (сначала всех соседей, потом соседей соседей). Использует очередь. Сложность **O(V + E)**. |
| Связность | Граф называется связным, если из любой вершины можно добраться до любой другой. Проверяется запуском DFS/BFS из одной вершины: если посещены все вершины — граф связный. |

## Полный код решения

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <locale.h>

using namespace std;

class Graph {
    int V; // Количество вершин
    vector<vector<int>> adj; // Список смежности

    // Рекурсивный DFS (вспомогательный)
    void dfsUtil(int v, vector<bool>& vis) {
        vis[v] = true;
        cout << v << " ";
        for (int u : adj[v]) if (!vis[u]) dfsUtil(u, vis);
    }

public:
    Graph(int v) : V(v), adj(v) {}

    void addEdge(int u, int v) {
        adj[u].push_back(v);
        adj[v].push_back(u); // Неориентированный граф
    }

    // Рекурсивный DFS (публичный)
    void DFS(int start) {
        vector<bool> vis(V, false);
        cout << "DFS: "; dfsUtil(start, vis); cout << endl;
    }

    // BFS
    void BFS(int start) {
        vector<bool> vis(V, false);
        queue<int> q;
        q.push(start); vis[start] = true;
        cout << "BFS: ";
        while (!q.empty()) {
            int v = q.front(); q.pop(); cout << v << " ";
            for (int u : adj[v]) {
                if (!vis[u]) { vis[u] = true; q.push(u); }
            }
        }
        cout << endl;
    }

    // ДОПОЛНИТЕЛЬНО (Вариант 4): Проверка на связность
    bool isConnected() {
        vector<bool> vis(V, false);
        dfsUtil(0, vis); // Запускаем обход из 1-й вершины
        for (bool v : vis) if (!v) return false; // Если хоть одну не посетили - граф несвязный
        return true;
    }

    // ЧАСТЬ 3: Вывод всех компонент связности
    void printComponents() {
        vector<bool> vis(V, false);
        int comp = 1;
        for (int i = 0; i < V; i++) {
            if (!vis[i]) {
                cout << "Компонента " << comp++ << ": ";
                dfsUtil(i, vis);
                cout << endl;
            }
        }
    }

    // ЧАСТЬ 3: Кратчайший путь (BFS)
    void shortestPath(int start, int end) {
        vector<int> dist(V, -1), prev(V, -1);
        queue<int> q;
        q.push(start); dist[start] = 0;

        while (!q.empty()) {
            int v = q.front(); q.pop();
            for (int u : adj[v]) {
                if (dist[u] == -1) {
                    dist[u] = dist[v] + 1;
                    prev[u] = v;
                    q.push(u);
                }
            }
        }

        if (dist[end] == -1) { cout << "Пути нет" << endl; return; }

        vector<int> path;
        for (int v = end; v != -1; v = prev[v]) path.push_back(v);

        cout << "Кратчайший путь " << start << "->" << end << ": ";
        for (int i = path.size() - 1; i >= 0; i--)
            cout << path[i] << (i > 0 ? " -> " : "\n");
    }
};

// ==================== ГЛАВНАЯ ФУНКЦИЯ ====================
int main() {
    setlocale(LC_ALL, "ru");

    // Создаем граф на 6 вершин (специально несвязный для проверки)
    Graph g(6);
    g.addEdge(0, 1);
    g.addEdge(1, 2);
    g.addEdge(2, 0); // Первая компонента (треугольник)

    g.addEdge(3, 4); // Вторая компонента (ребро)
    // Вершина 5 изолирована (третья компонента)

    cout << "=== 1. Обходы графа ===" << endl;
    g.DFS(0);
    g.BFS(0);

    cout << "\n=== 2. Проверка на связность (Вариант 4) ===" << endl;
    cout << "Граф связный? " << (g.isConnected() ? "Да" : "Нет") << endl;

    cout << "\n=== 3. Компоненты связности ===" << endl;
    g.printComponents();

    // Соединяем компоненты, чтобы проверить кратчайший путь
    g.addEdge(2, 3);
    g.addEdge(4, 5);

    cout << "\n=== 4. Кратчайший путь (BFS) ===" << endl;
    g.shortestPath(0, 5);

    return 0;
}
```

```
=== 2. Проверка на связность (Вариант 4) ===

=== 3. Компоненты связности ===

```

## Анализ сложности операций (Список смежности)

| Операция | Сложность | Обоснование |
|---|---|---|
| **Память** | **O(V + E)** | Храним только существующие рёбра. |
| **Добавление ребра** | **O(1)** | `push_back` в конец вектора. |
| **Проверка наличия ребра (u, v)** | **O(deg(u))** | Нужно просмотреть всех соседей вершины `u`. |
| **DFS / BFS** | **O(V + E)** | Каждую вершину посещаем 1 раз, каждое ребро проверяем 1 раз. |
| **Поиск кратчайшего пути (BFS)** | **O(V + E)** | Работает за счёт свойств обхода в ширину. |

## Преимущества и недостатки

**Список смежности** — оптимален по памяти для разреженных графов (O(V + E)), быстро перебирает соседей (O(deg(v))). Основной недостаток — проверка наличия конкретного ребра (u, v) занимает O(deg(u)), в отличие от матрицы смежности, где это O(1). Для плотных графов (E ≈ V²) выгоднее матрица.

**DFS (рекурсивный)** — код лаконичный, хорошо подходит для задач на структуру (компоненты, циклы, топологическая сортировка). Недостаток — глубокая рекурсия на больших графах может привести к переполнению стека; итеративная реализация с явным `std::stack` лишена этого минуса, но требует больше кода.

**BFS** — гарантированно находит кратчайший путь в невзвешенном графе, естественно работает «слоями». Недостаток — требует O(V) памяти под очередь и не подходит для взвешенных графов (там нужен алгоритм Дейкстры или A*). Кроме того, BFS не даёт информации о структуре (циклы, компоненты) так естественно, как DFS.

## Контрольные вопросы

**1. Что такое граф? Из каких элементов он состоит?**
Совокупность вершин (узлов) и рёбер (связей) между ними.

**2. Чем отличается ориентированный граф от неориентированного?**
В ориентированном рёбра имеют направление (из А в Б), в неориентированном связь двусторонняя.

**3. Что такое матрица смежности? Достоинства и недостатки?**
Квадратная таблица V×V. Плюс: O(1) проверка наличия ребра. Минус: занимает O(V²) памяти (плохо для разреженных графов).

**4. Что такое список смежности? Достоинства и недостатки?**
Массив списков соседей. Плюс: экономит память O(V+E). Минус: проверка ребра занимает O(deg(v)).

**5. Когда лучше использовать матрицу, а когда список?**
Матрицу — для плотных графов (много рёбер). Список — для разреженных.

**6. Сложность проверки ребра в матрице/списке?**
Матрица: O(1). Список: O(deg(u)).

**7. Сложность перебора соседей в матрице/списке?**
Матрица: O(V). Список: O(deg(u)).

**8. Что такое DFS? Как работает?**
Поиск в глубину. Идём по одной ветке до конца, затем возвращаемся и идём по другой. Использует рекурсию или стек.

**9. Какие задачи решаются с помощью DFS?**
Поиск компонент связности, проверка на циклы, топологическая сортировка.

**10. Что такое BFS? Как работает?**
Поиск в ширину. Сначала посещаем всех соседей, потом их соседей. Использует очередь.

**11. Какие задачи решаются с помощью BFS?**
Кратчайший путь в невзвешенном графе, поиск в ширину уровней.

**12. В чём отличие рекурсивной реализации DFS от итеративной?**
Рекурсивная использует стек вызовов (системный), итеративная — явную структуру `std::stack`.

**13. Почему BFS находит кратчайший путь, а DFS — нет?**
BFS исследует граф по уровням (сначала все на расстоянии 1, потом 2). DFS может уйти в длинную ветку, пропустив короткий путь.

**14. Как найти компоненты связности с помощью DFS?**
Запускаем цикл по всем вершинам. Если вершина не посещена, запускаем DFS и считаем это новой компонентой.

**15. Как проверить наличие цикла с помощью DFS?**
Если при обходе мы встречаем уже посещённую вершину, которая не является родителем текущей — есть цикл.
