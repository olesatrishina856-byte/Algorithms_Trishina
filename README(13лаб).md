## Теоретическая часть

| Концепция | Описание |
|---|---|
| Минимальное остовное дерево (MST) | Подграф, содержащий все вершины, являющийся деревом (без циклов) и имеющий минимальную сумму весов рёбер. |
| Алгоритм Краскала | Жадный алгоритм. Сначала все рёбра сортируются по весу. Затем мы проходим по ним и добавляем ребро в MST, если оно не создаёт цикла. |
| DSU (Disjoint Set Union) | Структура данных, позволяющая эффективно объединять множества и проверять, находятся ли два элемента в одном множестве. Использует две оптимизации: **сжатие путей** (path compression) и **объединение по рангу** (union by rank), что даёт почти O(1) на операцию. |
| Проверка связности | В связном графе MST всегда содержит ровно `V - 1` ребро. Если алгоритм Краскала завершил работу, а рёбер меньше — граф несвязный. |

## Полный код решения

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <locale.h>

using namespace std;

// Структура для ребра
struct Edge {
    int u, v, weight;
    // Оператор для сортировки по весу
    bool operator<(const Edge& other) const { return weight < other.weight; }
};

// Система непересекающихся множеств (DSU)
class DSU {
    vector<int> parent, rank;
public:
    DSU(int n) : parent(n), rank(n, 0) {
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    // Поиск корня со сжатием путей
    int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]);
    }
    // Объединение по рангу
    bool unite(int i, int j) {
        int rootI = find(i), rootJ = find(j);
        if (rootI == rootJ) return false; // Уже в одном множестве (будет цикл)
        if (rank[rootI] < rank[rootJ]) swap(rootI, rootJ);
        parent[rootJ] = rootI;
        if (rank[rootI] == rank[rootJ]) rank[rootI]++;
        return true;
    }
};

// Алгоритм Краскала
void kruskalMST(int V, vector<Edge>& edges) {
    sort(edges.begin(), edges.end()); // Сортируем ребра по весу
    DSU dsu(V);
    int totalWeight = 0, edgesCount = 0;

    cout << "=== Рёбра минимального остовного дерева ===" << endl;
    for (const auto& edge : edges) {
        if (dsu.unite(edge.u, edge.v)) {
            cout << edge.u << " - " << edge.v << " (вес: " << edge.weight << ")" << endl;
            totalWeight += edge.weight;
            edgesCount++;
            if (edgesCount == V - 1) break; // Дерево построено
        }
    }

    cout << "Общий вес MST: " << totalWeight << endl;

    // ДОПОЛНИТЕЛЬНО (Вариант 4): Проверка связности
    if (edgesCount == V - 1) {
        cout << ">>> Граф является СВЯЗНЫМ." << endl;
    } else {
        cout << ">>> ВНИМАНИЕ: Граф НЕСВЯЗНЫЙ! (Найдено компонент: " << V - edgesCount << ")" << endl;
    }
}

// ==================== ГЛАВНАЯ ФУНКЦИЯ ====================
int main() {
    setlocale(LC_ALL, "ru");

    int V = 5; // Количество вершин
    vector<Edge> edges = {
        {0, 1, 2}, {0, 3, 6}, {1, 2, 3},
        {1, 3, 8}, {1, 4, 5}, {2, 4, 7}, {3, 4, 9}
    };

    cout << "--- Тест 1: Связный граф ---" << endl;
    kruskalMST(V, edges);

    cout << "\n--- Тест 2: Несвязный граф (убрали ребро 3-4) ---" << endl;
    vector<Edge> disconnectedEdges = {
        {0, 1, 2}, {0, 3, 6}, {1, 2, 3},
        {1, 4, 5}, {2, 4, 7}
        // Вершина 3 теперь имеет только одно ребро (0-3), а 4 изолирована в своей подгруппе
    };
    kruskalMST(V, disconnectedEdges);

    return 0;
}
```

## Анализ сложности алгоритмов

| Операция | Сложность | Обоснование |
|---|---|---|
| **Сортировка рёбер** | **O(E log E)** | Основная часть времени работы алгоритма Краскала. |
| **Операции DSU (`find`, `unite`)** | **O(α(V)) ≈ O(1)** | Благодаря сжатию путей и объединению по рангу (α — обратная функция Аккермана, растёт крайне медленно). |
| **Общая сложность Краскала** | **O(E log E)** | Доминирует сортировка. Для разреженных графов это очень быстро. |
| **Проверка связности** | **O(1)** | Мы просто сравниваем количество добавленных рёбер с `V - 1`. |

## Преимущества и недостатки

**Алгоритм Краскала** — прост в реализации, отлично работает на **разреженных** графах (E << V²), так как его сложность O(E log E) зависит только от числа рёбер. Использование DSU с двумя оптимизациями (сжатие путей и объединение по рангу) даёт практически константное время на операцию, что делает алгоритм очень быстрым на практике. Недостаток — на плотных графах сортировка всех E ≈ V² рёбер может оказаться дороже, чем алгоритм Прима на матрице смежности.

**Алгоритм Прима** — эффективнее на **плотных** графах (O(V²) с матрицей или O((V+E) log V) с `priority_queue`), не требует сортировки всех рёбер. Недостаток — на разреженных графах проигрывает Краскалу, а реализация с DSU невозможна (используется другой подход — наращивание дерева от вершины).

**DSU** — незаменимая вспомогательная структура не только для Краскала, но и для многих других задач (проверка связности в динамическом графе, задача о компонентах, Kruskal reconstruction tree). Главное ограничение — DSU не поддерживает операцию разбиения множества, только объединение.

**Проверка связности** — в рамках Краскала она бесплатна: просто сравниваем число добавленных рёбер с `V − 1`. Это элегантный побочный результат алгоритма.

## Контрольные вопросы

**1. Что такое минимальное остовное дерево (MST)?**
Это подграф, включающий все вершины графа, не имеющий циклов, с минимально возможной суммой весов рёбер.

**2. Какие свойства имеет MST?**
Содержит V−1 рёбер. Единственное, если все веса уникальны. Обладает свойством разреза (минимальное ребро через разрез принадлежит MST) и свойством цикла (максимальное ребро в цикле не принадлежит MST).

**3. В чём заключается идея алгоритма Прима?**
Начинаем с одной вершины и наращиваем дерево, на каждом шаге добавляя самое дешёвое ребро, соединяющее текущее дерево с новой, ещё не включённой вершиной.

**4. Какова временная сложность алгоритма Прима на матрице смежности?**
**O(V²)** (так как нужно V раз найти минимум среди V вершин).

**5. Какова временная сложность алгоритма Прима с приоритетной очередью?**
**O((V+E) log V)**.

**6. В чём заключается идея алгоритма Краскала?**
Сортируем все рёбра по весу. Идём по списку и добавляем ребро в MST, если оно не образует цикл с уже добавленными.

**7. Что такое DSU и как она используется в алгоритме Краскала?**
Система непересекающихся множеств. Позволяет за почти O(1) проверить, находятся ли концы ребра в одном множестве (что означало бы создание цикла).

**8. Какова временная сложность алгоритма Краскала?**
**O(E log E)** из-за необходимости сортировки рёбер.

**9. В каких случаях алгоритм Прима эффективнее?**
На **плотных** графах (где E близко к V²), особенно при использовании матрицы смежности.

**10. В каких случаях алгоритм Краскала эффективнее?**
На **разреженных** графах (где E << V²), так как сложность зависит от E, а не от V².

**11. Как проверить, что построенное дерево является минимальным?**
Достаточно убедиться, что алгоритм (Прима или Краскала) отработал без ошибок — они математически гарантируют минимальность.

**12. Что произойдёт, если граф не связный?**
Алгоритм построит **минимальный остовный лес** (Minimum Spanning Forest) — набор деревьев для каждой компоненты связности. Полного MST не существует.

**13. Как модифицировать алгоритмы для поиска максимального остовного дерева?**
Отсортировать рёбра по убыванию веса (для Краскала) или искать максимум (для Прима). Либо просто инвертировать знаки весов.

**14. Где применяются MST в реальной жизни?**
Прокладка кабелей/труб (минимизация затрат), кластеризация данных, построение дорог, аппроксимация задачи коммивояжёра.

**15. Как найти второй по минимальности вес MST?**
Найти MST. Затем поочерёдно удалять каждое ребро из MST, искать MST без него, и выбирать из получившихся вариантов тот, чей вес минимален среди отличных от исходного.
