## Теоретическая часть

| Концепция | Описание |
|---|---|
| Динамическое программирование (ДП) | Метод решения задач путём разбиения на подзадачи. Использует принципы: оптимальная подструктура (решение задачи зависит от решений подзадач) и перекрывающиеся подзадачи (одни и те же подзадачи решаются многократно, результаты кэшируются). |
| Задача о рюкзаке (0/1) | Есть рюкзак вместимостью `W` и `N` предметов с весами `wt[i]` и стоимостью `val[i]`. Нужно максимизировать стоимость, не превысив вес. 2D-таблица `dp[i][w]` хранит максимальную стоимость для первых `i` предметов и вместимости `w`. |
| LCS для 3 строк | Обобщение классической LCS. Строится 3D-таблица `dp[i][j][k]`. Если символы `X[i-1] == Y[j-1] == Z[k-1]`, то длина увеличивается на 1 от `dp[i-1][j-1][k-1]`. Иначе берётся максимум из трёх возможных вариантов сдвига (`dp[i-1][j][k]`, `dp[i][j-1][k]`, `dp[i][j][k-1]`). |

## Полный код решения

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <locale.h>

using namespace std;

// ==================== 1. ЗАДАЧА О РЮКЗАКЕ (2D таблица) ====================
void knapsack(int W, const vector<int>& wt, const vector<int>& val) {
    int n = wt.size();
    // dp[i][w] - макс. стоимость для первых i предметов при весе w
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));

    for (int i = 1; i <= n; i++) {
        for (int w = 1; w <= W; w++) {
            if (wt[i - 1] <= w)
                dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - wt[i - 1]] + val[i - 1]);
            else
                dp[i][w] = dp[i - 1][w];
        }
    }

    cout << "Максимальная стоимость: " << dp[n][W] << endl;

    // Восстановление предметов
    cout << "Выбранные предметы (индексы): ";
    int w = W;
    for (int i = n; i > 0; i--) {
        if (dp[i][w] != dp[i - 1][w]) {
            cout << i - 1 << " ";
            w -= wt[i - 1];
        }
    }
    cout << endl;
}

// ==================== 2. LCS ДЛЯ ТРЁХ СТРОК (3D таблица) ====================
void lcs3(const string& X, const string& Y, const string& Z) {
    int m = X.length(), n = Y.length(), p = Z.length();
    // 3D таблица
    vector<vector<vector<int>>> dp(m + 1, vector<vector<int>>(n + 1, vector<int>(p + 1, 0)));

    // Заполнение таблицы
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            for (int k = 1; k <= p; k++) {
                if (X[i - 1] == Y[j - 1] && X[i - 1] == Z[k - 1]) {
                    dp[i][j][k] = dp[i - 1][j - 1][k - 1] + 1;
                } else {
                    dp[i][j][k] = max({dp[i - 1][j][k], dp[i][j - 1][k], dp[i][j][k - 1]});
                }
            }
        }
    }

    cout << "Длина LCS для 3 строк: " << dp[m][n][p] << endl;

    // Восстановление подпоследовательности (обратный ход)
    string res = "";
    int i = m, j = n, k = p;
    while (i > 0 && j > 0 && k > 0) {
        if (X[i - 1] == Y[j - 1] && X[i - 1] == Z[k - 1]) {
            res = X[i - 1] + res;
            i--; j--; k--;
        } else {
            // Ищем, откуда пришли (где максимум)
            if (dp[i - 1][j][k] >= dp[i][j - 1][k] && dp[i - 1][j][k] >= dp[i][j][k - 1]) i--;
            else if (dp[i][j - 1][k] >= dp[i - 1][j][k] && dp[i][j - 1][k] >= dp[i][j][k - 1]) j--;
            else k--;
        }
    }
    cout << "LCS: " << res << endl;
}

// ==================== ГЛАВНАЯ ФУНКЦИЯ ====================
int main() {
    setlocale(LC_ALL, "ru");

    cout << "=== 1. Задача о рюкзаке (0/1) ===" << endl;
    int W = 10;
    vector<int> wt = {2, 3, 4, 5}; // Веса
    vector<int> val = {3, 4, 5, 8}; // Ценности
    knapsack(W, wt, val);

    cout << "\n=== 2. LCS для трёх строк ===" << endl;
    string X = "ABCBDAB";
    string Y = "BDCABA";
    string Z = "BADCBA"; // Добавили третью строку
    lcs3(X, Y, Z);

    return 0;
}
```

## Анализ сложности алгоритмов

| Алгоритм | Временная сложность | Пространственная сложность | Обоснование |
|---|---|---|---|
| **Рюкзак (2D)** | **O(N · W)** | **O(N · W)** | Два вложенных цикла (по предметам и весу), таблица размером N×W. |
| **LCS (2 строки)** | **O(m · n)** | **O(m · n)** | Таблица размером m×n. |

## Преимущества и недостатки

**Задача о рюкзаке (2D-таблица)** — даёт точное оптимальное решение и позволяет восстановить конкретный набор предметов обратным проходом. Работает за O(N·W), что приемлемо для умеренных вместимостей. Основной недостаток — при больших весах (например, W = 10⁹) или вещественных весах таблица становится неподъёмной; тогда применяют масштабирование (умножение на 100/1000) или переходят к приближённым схемам (FPTAS) либо ветвлению и границам (branch and bound).

**LCS для трёх строк** — естественное обобщение классического алгоритма, легко расширяется и на большее число строк (ценой роста размерности). Основной недостаток — кубическая сложность по времени и памяти O(m·n·p): уже при строках по 1000 символов таблица занимает ~10⁹ ячеек, что не помещается в память. Оптимизация Хиршберга позволяет сократить память до O(min(m, n)) для двух строк, но для трёх строк она применима лишь с ограничениями.

**Динамическое программирование в целом** — даёт гарантированно оптимальное решение для задач с оптимальной подструктурой и перекрывающимися подзадачами, но требует явного хранения таблицы (или мемоизации), что ограничивает применимость на больших входах. Альтернативы: жадные алгоритмы (быстрее, но не всегда оптимальны) и метаэвристики (генетические алгоритмы, имитация отжига) — дают приближённые решения за приемлемое время.

## Контрольные вопросы

**1. Что такое динамическое программирование? Какие принципы лежат в его основе?**
Это метод оптимизации, разбивающий задачу на подзадачи. Основан на принципах: оптимальная подструктура (оптимальное решение содержит оптимальные решения подзадач) и перекрывающиеся подзадачи (результаты сохраняются, чтобы не вычислять их повторно).

**2. В чём разница между top-down и bottom-up?**
Top-down (мемоизация) — рекурсивный подход от большой задачи к малым с сохранением результатов. Bottom-up (табличный) — итеративный подход от малых подзадач к большим.

**3. Как формулируется задача о рюкзаке (0/1)?**
Есть рюкзак вместимостью W и N предметов. У каждого есть вес и ценность. Нужно выбрать предметы так, чтобы максимизировать ценность, не превысив вес. Каждый предмет можно взять только 1 раз.

**4. Какова временная сложность решения задачи о рюкзаке методом ДП?**
O(N · W), где N — количество предметов, W — вместимость.

**5. Почему для оптимизации памяти нужно проходить по весам в обратном порядке?**
При использовании одномерного массива `dp[w]` мы обновляем его, опираясь на значения из предыдущего шага. Если идти слева направо, мы можем использовать значение, которое только что обновили (взять предмет дважды).

**6. Как восстановить выбранные предметы?**
Идти по таблице с конца. Если `dp[i][w] != dp[i-1][w]`, значит предмет `i` был взят, вычитаем его вес из `w` и переходим к `i-1`.

**7. Как формулируется задача LCS?**
Найти самую длинную подпоследовательность, которая присутствует в двух (или более) заданных строках.

**8. Какова временная сложность алгоритма LCS?**
O(m · n) для двух строк, где m и n — их длины.

**9. В чём разница между подпоследовательностью и подстрокой?**
Подстрока — непрерывный кусок строки. Подпоследовательность — символы в исходном порядке, но могут идти с пропусками.

**10. Как восстановить LCS?**
Идти от правого нижнего угла таблицы. Если символы совпадают, добавляем символ к результату и идём по диагонали. Если нет — идём в сторону большего значения.

**11. Какие ещё задачи решаются с помощью ДП?**
Числа Фибоначчи, задача о монетах, расстояние Левенштейна, умножение матриц.

**12. В чём отличие 0/1 рюкзака от рюкзака с повторениями?**
В 0/1 каждый предмет можно взять один раз, в рюкзаке с повторениями — бесконечное количество раз.

**13. Можно ли решить LCS за меньшее время, чем O(m·n)?**
В общем случае нет (существуют оптимизации для специфических случаев, например, алгоритм Ханта-Шиманского).

**14. Как адаптировать ДП для LCS трёх строк?**
Использовать трёхмерную таблицу `dp[i][j][k]`.

**15. Как модифицировать задачу о рюкзаке для многократного использования предметов?**
Изменить формулу: `dp[w] = max(dp[w], dp[w - wt[i]] + val[i])` при прямом проходе по весам.
