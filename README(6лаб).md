## Теоретическая часть

| Концепция | Описание |
|---|---|
| Рекурсия | Метод программирования, при котором функция вызывает саму себя для решения подзадач меньшего размера. Обязательно наличие базового случая (условия остановки) и шага рекурсии (вызова с изменёнными параметрами). |
| Сложность рекурсивных алгоритмов | Факториал и НОД работают за O(n) и O(log n) соответственно (глубина рекурсии). Наивный Фибоначчи имеет сложность O(2^n), а Ханойские башни — O(2^n), так как количество ходов равно 2^n − 1. |
| Пузырьковая сортировка (Bubble Sort) | Сравнивает соседние элементы и меняет их местами. Сложность O(n²), но с флагом swapped на почти отсортированных данных может работать за O(n). |
| Сортировка вставками (Insertion Sort) | Берет элемент и вставляет его на нужное место в уже отсортированной части. Сложность O(n²), но очень эффективна на почти отсортированных данных (O(n)). |

## Полный код решения

```cpp
#include <iostream>
#include <vector>
#include <locale.h>

using namespace std;

// ==================== ЧАСТЬ 1: РЕКУРСИВНЫЕ АЛГОРИТМЫ ====================

// 1. Факториал
long long factorial(int n) {
    if (n <= 1) return 1; // Базовый случай
    return n * factorial(n - 1); // Шаг рекурсии
}

// 2. Числа Фибоначчи
long long fibonacci(int n) {
    if (n <= 1) return n; // Базовый случай
    return fibonacci(n - 1) + fibonacci(n - 2); // Шаг рекурсии
}

// 3. НОД (Алгоритм Евклида)
int gcd(int a, int b) {
    if (b == 0) return a; // Базовый случай
    return gcd(b, a % b); // Шаг рекурсии
}

// 4. Ханойские башни (3 диска)
void hanoi(int n, char from, char to, char aux) {
    if (n == 1) { // Базовый случай
        cout << "Диск 1: " << from << " -> " << to << endl;
        return;
    }
    hanoi(n - 1, from, aux, to); // Переносим n-1 дисков на вспомогательный стержень
    cout << "Диск " << n << ": " << from << " -> " << to << endl;
    hanoi(n - 1, aux, to, from); // Переносим n-1 дисков на целевой стержень
}

// ==================== ЧАСТЬ 2: СОРТИРОВКИ ====================

// Пузырьковая сортировка с подсчётом
void bubbleSort(int arr[], int n, long long& comps, long long& swaps) {
    comps = 0; swaps = 0;
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            comps++; // Считаем сравнение
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swaps++; // Считаем обмен
                swapped = true;
            }
        }
        if (!swapped) break; // Оптимизация
    }
}

// Сортировка вставками с подсчётом
void insertionSort(int arr[], int n, long long& comps, long long& swaps) {
    comps = 0; swaps = 0;
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0) {
            comps++; // Считаем сравнение
            if (arr[j] > key) {
                arr[j + 1] = arr[j]; // Сдвиг элемента (считаем как обмен/перемещение)
                swaps++;
                j--;
            }
            else {
                break;
            }
        }
        arr[j + 1] = key;
    }
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) cout << arr[i] << " ";
    cout << endl;
}

// ==================== ГЛАВНАЯ ФУНКЦИЯ ====================
int main() {
    setlocale(LC_ALL, "ru");

    cout << "=== ЧАСТЬ 1. РЕКУРСИВНЫЕ АЛГОРИТМЫ ===" << endl;
    cout << "1. Факториал 5! = " << factorial(5) << endl;
    cout << "2. Фибоначчи (10-е число) = " << fibonacci(10) << endl;
    cout << "3. НОД(48, 18) = " << gcd(48, 18) << endl;
    cout << "4. Ханойские башни (3 диска):" << endl;
    hanoi(3, 'A', 'C', 'B');
    cout << endl;

    cout << "=== ЧАСТЬ 2. ПРОСТЫЕ СОРТИРОВКИ ===" << endl;

    // Тестовый массив
    int arr1[] = { 5, 2, 9, 1, 5, 6 };
    int arr2[] = { 5, 2, 9, 1, 5, 6 };
    int n = sizeof(arr1) / sizeof(arr1[0]);

    cout << "Исходный массив: "; printArray(arr1, n);

    long long bubbleComps = 0, bubbleSwaps = 0;
    bubbleSort(arr1, n, bubbleComps, bubbleSwaps);
    cout << "\nПузырьковая сортировка:" << endl;
    cout << "Отсортированный массив: "; printArray(arr1, n);
    cout << "Сравнений: " << bubbleComps << ", Обменов: " << bubbleSwaps << endl;

    long long insertComps = 0, insertSwaps = 0;
    insertionSort(arr2, n, insertComps, insertSwaps);
    cout << "\nСортировка вставками:" << endl;
    cout << "Отсортированный массив: "; printArray(arr2, n);
    cout << "Сравнений: " << insertComps << ", Обменов (сдвигов): " << insertSwaps << endl;

    return 0;
}
```

## Преимущества и недостатки
Рекурсивные алгоритмы (факториал, НОД, Ханойские башни) делают код лаконичным и легко читаемым, но требуют дополнительной памяти под стек вызовов. Наивная рекурсия для чисел Фибоначчи крайне неэффективна (O(2^n)) из-за дублирования вычислений.

Сортировка вставками на практике показывает себя лучше пузырьковой на почти отсортированных данных, так как совершает меньше сравнений и обменов. Однако обе они имеют квадратичную сложность O(n²) в среднем, что делает их непригодными для больших массивов.

**Контрольные вопросы**

1.Что такое рекурсия? Из каких компонентов состоит рекурсивная функция?
Это вызов функцией самой себя. Состоит из базового случая (условие остановки) и шага рекурсии (вызов с меньшими параметрами).

2.Что такое базовый случай рекурсии? Почему он важен?
Это условие, при котором функция перестает вызывать себя. Без него произойдет переполнение стека (Stack Overflow) и программа упадет.

3.Чем отличается прямая рекурсия от косвенной?
Прямая — функция вызывает саму себя. Косвенная — функция A вызывает функцию B, а та в свою очередь вызывает A.

4.Что такое хвостовая рекурсия? В чём её преимущество?
Это рекурсия, где рекурсивный вызов является последней операцией в функции. Преимущество: компилятор может оптимизировать её в обычный цикл, экономя память стека.

5.Какова временная сложность рекурсивного вычисления чисел Фибоначчи? Почему?
O(2^n). Каждый вызов порождает два новых, и вычисления дублируются (например, fib(3) вычисляется много раз).

6.Как можно оптимизировать рекурсивное вычисление Фибоначчи?
Использовать мемоизацию (сохранение уже вычисленных значений в массиве) или переписать алгоритм итеративно.

7.В чём отличие рекурсивной реализации от итеративной?
Рекурсивная обычно короче и читабельнее, но тратит память на стек вызовов. Итеративная использует циклы и работает быстрее/экономнее по памяти.

8.Какова сложность пузырьковой сортировки? Когда она становится O(n)?
O(n²). Она становится O(n) в лучшем случае, если массив уже отсортирован (и если используется флаг swapped, чтобы прервать цикл).

9.Чем сортировка вставками отличается от сортировки выбором?
Вставки ищут место для текущего элемента в уже отсортированной части. Выбор ищет минимальный элемент в неотсортированной части и меняет его с текущим.

10.Какая из простых сортировок является устойчивой? Что это значит?
Пузырьковая и вставками. Устойчивость — сохранение относительного порядка равных элементов.

11.Какая из простых сортировок работает лучше на почти отсортированных данных?
Сортировка вставками (она может показать сложность, близкую к O(n)).

12.Как реализовать пузырьковую сортировку с оптимизацией?
Добавить логический флаг swapped. Если за проход не было ни одного обмена, значит массив отсортирован и нужно выйти из цикла.

13.Что такое рекурсивный поиск с возвратом (backtracking)?
Метод перебора, при котором мы идем вглубь, а если зашли в тупик — возвращаемся на шаг назад и пробуем другой путь (как в лабиринте).

14.Как рекурсивно обойти лабиринт?
Находясь в клетке, помечаем её как посещенную. Проверяем, не финиш ли это. Затем рекурсивно пробуем пойти во все 4 стороны (верх, низ, лево, право), если там нет стены и мы не были.

15.Какова сложность Ханойских башен? Сколько ходов нужно для перемещения n дисков?
Временная сложность O(2^n). Количество ходов 2^n − 1.
