## Теоретическая часть

| Концепция | Описание |
|---|---|
| О-нотация (Big O) | Математическая запись, описывающая асимптотическое поведение функции. Показывает, как быстро растёт время работы алгоритма при увеличении входных данных, отбрасывая константы и младшие члены. |
| Классы сложности | O(1) - константная, O(log n) - логарифмическая, O(n) - линейная, O(n log n) - линейно-логарифмическая, O(n2) - квадратичная. |
| Шаблоны классов | Позволяют создавать классы, работающие с разными типами данных. Объявляются с помощью `template <typename T>`. |
| Амортизированный анализ | Оценка среднего времени выполнения операции в худшем случае на длинной последовательности операций. Пример: расширение динамического массива (амортизированное О(1) для `push_back`). |

## Полный код решения

```cpp
#include <iostream>
#include <stdexcept>
#include <chrono>
#include <queue>
#include <vector>
#include <string>
#include <locale.h>

using namespace std;
using namespace chrono;

//ШАБЛОННЫЙ КЛАСС QUEUE<T>
template <typename T>
class Queue {
private:
    T* data;          // динамический массив
    int capacity;     // текущая ёмкость
    int head;         // индекс первого элемента
    int tail;         // индекс для следующего добавления
    int count;        // количество элементов

    // O(n) - вызывается редко, амортизированно O(1)
    void resize() {
        int newCap = capacity * 2;
        T* newData = new T[newCap];
        for (int i = 0; i < count; i++) {
            newData[i] = data[(head + i) % capacity];
        }
        delete[] data;
        data = newData;
        capacity = newCap;
        head = 0;
        tail = count;
    }

public:
    Queue(int initialCapacity = 10)
        : capacity(initialCapacity), head(0), tail(0), count(0) {
        data = new T[capacity];
    }

    ~Queue() {
        delete[] data;
    }

    // O(1) амортизированное
    void enqueue(const T& value) {
        if (count == capacity) resize();
        data[tail] = value;
        tail = (tail + 1) % capacity;
        count++;
    }

    // O(1)
    T dequeue() {
        if (isEmpty()) throw out_of_range("Очередь пуста");
        T value = data[head];
        head = (head + 1) % capacity;
        count--;
        return value;
    }

    // O(1)
    T front() const {
        if (isEmpty()) throw out_of_range("Очередь пуста");
        return data[head];
    }

    // O(1)
    bool isEmpty() const { return count == 0; }

    // O(1)
    int size() const { return count; }

    // O(n) - только для демонстрации
    void print() const {
        cout << "[";
        for (int i = 0; i < count; i++) {
            cout << data[(head + i) % capacity];
            if (i < count - 1) cout << ", ";
        }
        cout << "]";
    }
};

//ИЗМЕРЕНИЕ ВРЕМЕНИ
template <typename Func>
long long measureTime(Func func) {
    auto start = high_resolution_clock::now();
    func();
    auto end = high_resolution_clock::now();
    return duration_cast<microseconds>(end - start).count();
}

//ГЛАВНАЯ ФУНКЦИЯ
int main() {
    setlocale(LC_ALL, "ru");

    // --- Анализ сложности ---
    cout << "=== Сложность операций Queue<T> ===" << endl;
    cout << "enqueue: O(1) амортизированное" << endl;
    cout << "dequeue: O(1)" << endl;
    cout << "front:   O(1)" << endl;
    cout << "isEmpty: O(1)" << endl;
    cout << "size:    O(1)" << endl;

    // --- Демонстрация c int ---
    cout << "\n=== Queue<int> ===" << endl;
    Queue<int> q1(3);
    q1.enqueue(10);
    q1.enqueue(20);
    q1.enqueue(30);
    q1.enqueue(40); // вызовет resize
    q1.enqueue(50);
    cout << "Очередь: ";
    q1.print();
    cout << "\nfront = " << q1.front() << ", size = " << q1.size() << endl;
    cout << "dequeue = " << q1.dequeue() << endl;
    cout << "После dequeue: ";
    q1.print();
    cout << ", size = " << q1.size() << endl << endl;

    // --- Демонстрация c string ---
    cout << "=== Queue<string> ===" << endl;
    Queue<string> q2(3);
    q2.enqueue("Первый");
    q2.enqueue("Второй");
    q2.enqueue("Третий");
    cout << "Очередь: ";
    q2.print();
    cout << "\nfront = " << q2.front() << endl << endl;

    // --- Сравнение с STL ---
    cout << "=== Сравнение с std::queue ===" << endl;
    cout << "Размер\t\tMy Queue (мкс)\tSTL queue (мкс)" << endl;

    vector<int> sizes = { 10000, 100000, 500000, 1000000 };

    for (int n : sizes) {
        long long myTime = measureTime([&]() {
            Queue<int> q(n);
            for (int i = 0; i < n; i++) q.enqueue(i);
            while (!q.isEmpty()) q.dequeue();
        });

        long long stlTime = measureTime([&]() {
            queue<int> q;
            for (int i = 0; i < n; i++) q.push(i);
            while (!q.empty()) q.pop();
        });

        cout << n << "\t\t" << myTime << "\t\t" << stlTime << endl;
    }

    return 0;
}
```

**Контрольные вопросы**
1.Что такое О-нотация (Big O) и зачем она нужна?
Это математическая запись, описывающая асимптотическое поведение функции. Нужна для оценки эффективности алгоритма при больших объёмах данных, игнорируя константы.

2.Какая сложность у доступа к элементу массива по индексу? Почему?
O(1). Адрес элемента вычисляется математически: base_address + index * sizeof(T), не зависит от размера массива.

3.Какая сложность у бинарного поиска? Почему?
O(log n). На каждом шаге область поиска делится пополам.

4.Что означает сложность O(n log n)? Приведите пример.
Время растёт как произведение линейного и логарифмического. Пример: быстрая сортировка, сортировка слиянием.

5.Что такое амортизированный анализ? Приведите пример.
Оценка среднего времени операции на длинной последовательности. Пример: добавление в динамический массив (вектор), когда при переполнении память перевыделяется.

6.Какая сложность у двух вложенных циклов по n итераций каждый?
O(n2).

7.Какая сложность у рекурсивного вычисления чисел Фибоначчи?
O(2^n) — экспоненциальная.

8.Что такое шаблоны функций? Как их объявить?
Это функции, работающие с разными типами. Объявление: template <typename T> T func(T a, T b) { ... }.

9.Что такое шаблоны классов? Как их объявить?
Классы, параметризованные типом. Объявление: template <typename T> class MyClass { ... };.

10.В чём преимущество шаблонов перед перегрузкой функций?
Позволяют избежать дублирования кода. Одна шаблонная функция заменяет множество перегруженных версий для разных типов.

11.Как указать, что шаблонный параметр — тип?
С помощью ключевого слова typename или class: template <typename T>.

12.Можно ли создать шаблон с несколькими параметрами типов?
Да: template <typename T1, typename T2> class Pair { ... };.

13.Как провести экспериментальное измерение времени выполнения?
Использовать библиотеку <chrono>, замеряя время до и после выполнения функции с помощью high_resolution_clock.

14.Почему при измерении времени нужно выполнять операцию многократно?
Чтобы сгладить случайные колебания (шум) и получить статистически значимый результат, так как одна операция может выполняться слишком быстро.

15.Что важнее: сложность алгоритма или константа?
Для больших n важнее сложность (асимптотика). Для малых n константа может играть решающую роль.
