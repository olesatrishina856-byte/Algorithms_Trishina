## Теоретическая часть

| Концепция | Описание |
|---|---|
| Бинарное дерево поиска (BST) | Дерево, в котором для каждого узла выполняется правило: все значения в левом поддереве меньше узла, а все значения в правом — больше. |
| Симметричный обход (in-order) | Обход «Левый → Корень → Правый». Для BST этот обход всегда выдаёт элементы в **отсортированном по возрастанию порядке**. |
| LCA (Lowest Common Ancestor) | Наименьший общий предок двух узлов — самый глубокий узел, который является предком для обоих заданных узлов. В BST его можно найти рекурсивно: если оба значения меньше текущего узла — идём влево, если больше — вправо. Как только пути расходятся (одно значение слева, другое справа), текущий узел и есть LCA. |

#include <iostream>
#include <algorithm>
#include <locale.h>

using namespace std;

// Узел дерева
struct Node {
    int data;
    Node* left; Node* right;
    Node(int val) : data(val), left(nullptr), right(nullptr) {}
};

class BST {
    Node* root;

    Node* insert(Node* n, int k) {
        if (!n) return new Node(k);
        if (k < n->data) n->left = insert(n->left, k);
        else if (k > n->data) n->right = insert(n->right, k);
        return n;
    }

    Node* search(Node* n, int k) {
        if (!n || n->data == k) return n;
        return k < n->data ? search(n->left, k) : search(n->right, k);
    }

    void inOrder(Node* n) {
        if (!n) return;
        inOrder(n->left); cout << n->data << " "; inOrder(n->right);
    }

    // ВАРИАНТ 4: Поиск наименьшего общего предка (LCA)
    Node* findLCA(Node* n, int n1, int n2) {
        if (!n) return nullptr;
        if (n->data > n1 && n->data > n2) return findLCA(n->left, n1, n2);
        if (n->data < n1 && n->data < n2) return findLCA(n->right, n1, n2);
        return n; // Нашли точку расхождения - это LCA
    }

    Node* remove(Node* n, int k) {
        if (!n) return nullptr;
        if (k < n->data) n->left = remove(n->left, k);
        else if (k > n->data) n->right = remove(n->right, k);
        else {
            if (!n->left) { Node* t = n->right; delete n; return t; }
            if (!n->right) { Node* t = n->left; delete n; return t; }
            Node* t = n->right;
            while (t && t->left) t = t->left;
            n->data = t->data;
            n->right = remove(n->right, t->data);
        }
        return n;
    }

    int height(Node* n) { return !n ? 0 : 1 + max(height(n->left), height(n->right)); }

    void destroy(Node* n) { if (n) { destroy(n->left); destroy(n->right); delete n; } }

public:
    BST() : root(nullptr) {}
    ~BST() { destroy(root); }

    void insert(int k) { root = insert(root, k); }
    bool search(int k) { return search(root, k) != nullptr; }
    void inOrder() { inOrder(root); cout << endl; }
    int findLCA(int n1, int n2) { Node* res = findLCA(root, n1, n2); return res ? res->data : -1; }
    void remove(int k) { root = remove(root, k); }
    int getHeight() { return height(root); }

    int getMin() { if (!root) return -1; Node* c = root; while (c->left) c = c->left; return c->data; }
    int getMax() { if (!root) return -1; Node* c = root; while (c->right) c = c->right; return c->data; }
};

## Анализ сложности операций

| Операция | Средний случай | Худший случай (вырожденное дерево) | Обоснование |
|---|---|---|---|
| `insert` | **O(log n)** | **O(n)** | В среднем дерево сбалансировано, и мы делим область поиска пополам на каждом шаге. Если вставлять по возрастанию, дерево станет «бамбуком». |
| `search` | **O(log n)** | **O(n)** | Аналогично вставке — спускаемся от корня. |
| `inOrder` | **O(n)** | **O(n)** | Нужно посетить каждый узел ровно один раз. |
| `findLCA` | **O(log n)** | **O(n)** | Спуск по одной ветке до нахождения нужного узла. |
| `remove` | **O(log n)** | **O(n)** | Поиск узла + (в худшем случае) поиск минимума в правом поддереве. |

## Преимущества и недостатки

**BST (бинарное дерево поиска)** — обеспечивает O(log n) в среднем на всех операциях, при этом хранит элементы в упорядоченном виде и позволяет быстро находить минимум/максимум, а также делать сортированный обход без дополнительной памяти. Основной недостаток — при неудачном порядке вставки (например, по возрастанию/убыванию) дерево вырождается в связный список, и сложность операций падает до O(n). Для гарантии O(log n) нужны самобалансирующиеся деревья (AVL, красно-чёрные).

**Рекурсивная реализация** — делает код лаконичным и понятным, но расходует память на стек вызовов; при очень глубоком (вырожденном) дереве может привести к переполнению стека. Итеративные реализации (например, обход с явным стеком) лишены этого недостатка.

**LCA в BST** — благодаря свойству упорядоченности решается рекурсивным спуском за O(log n) без использования дополнительной памяти и без хранения указателей на родителей, что является большим преимуществом перед общим алгоритмом для произвольных деревьев.

## Контрольные вопросы

**1. Что такое бинарное дерево? Из каких элементов оно состоит?**
Иерархическая структура, где у каждого узла не более 2 потомков. Состоит из узлов (содержат данные и указатели на левого/правого потомка).

**2. В чём отличие бинарного дерева от BST?**
В BST соблюдается строгое правило: левое поддерево < узел < правое поддерево. В обычном бинарном дереве такого ограничения нет.

**3. Какие существуют виды обхода?**
Прямой (Pre-order: Корень-Левый-Правый), Симметричный (In-order: Левый-Корень-Правый), Обратный (Post-order: Левый-Правый-Корень), Уровневый (BFS).

**4. Какой обход даёт отсортированную последовательность для BST?**
Симметричный (In-order).

**5. Какова сложность операций в BST? От чего она зависит?**
В среднем O(log n), в худшем O(n). Зависит от высоты дерева (сбалансировано ли оно).

**6. Что происходит с BST, если вставлять элементы в отсортированном порядке?**
Дерево становится несбалансированным (вырождается в связный список), и сложность операций падает до O(n).

**7. Какие три случая при удалении узла из BST?**
1) Узел — лист (просто удаляем). 2) Узел имеет одного потомка (заменяем узел потомком). 3) Узел имеет двух потомков (находим минимум в правом поддереве, копируем его значение в узел и удаляем этот минимум).

**8. Как найти наименьший/наибольший элемент?**
Наименьший — идти по левым потомкам до конца. Наибольший — по правым.

**9. Как вычислить высоту рекурсивно?**
`height(node) = 1 + max(height(left), height(right))`. База: если узел пуст, высота 0.

**10. Что такое LCA?**
Самый глубокий узел, который является предком для двух заданных узлов.

**11. Как проверить, является ли дерево BST?**
Сделать In-order обход и проверить, что последовательность строго возрастает.

**12. Что такое сбалансированное дерево?**
Дерево, у которого разница высот левого и правого поддеревьев для каждого узла не превышает 1 (AVL-дерево). Важно для гарантии O(log n).

**13. Как преобразовать несбалансированное BST в сбалансированное?**
Сделать In-order обход в массив, а затем рекурсивно строить дерево из середины массива.

**14. Как восстановить дерево по обходам?**
По In-order можно узнать структуру, а по Pre-order или Post-order — корень. Рекурсивно восстанавливаем левые и правые поддеревья.

**15. Как реализовать итеративный обход?**
Использовать явный стек (`std::stack`) для хранения узлов.
