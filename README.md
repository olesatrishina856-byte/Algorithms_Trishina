## Теоретическая часть

Связный список — это базовая динамическая структура данных, состоящая из узлов. В отличие от массива, элементы списка не хранятся в памяти непрерывно. Каждый узел содержит сами данные и указатель(и) на соседние узлы.

**Односвязный список:** каждый узел хранит данные и указатель `next` (на следующий узел). Позволяет эффективно добавлять и удалять элементы в начале (за O(1)), но для удаления с конца или поиска требуется проход по всему списку (O(n)).

**Двусвязный список:** каждый узел содержит данные, указатель `next` (вперед) и указатель `prev` (назад). Это позволяет обходить список в обоих направлениях и удалять элементы с конца за O(1), так как мы сразу имеем доступ к предыдущему узлу.

**Быстрая сортировка (QuickSort)** — алгоритм сортировки, использующий стратегию «разделяй и властвуй». Выбирается опорный элемент (pivot) (в данной работе — последний элемент подсписка). Список разделяется так, чтобы слева от опорного были элементы меньше него, а справа — больше (или равные). Рекурсивно применяется сортировка к левой и правой частям. Средняя сложность алгоритма — O(n log n), худшая (при неудачном выборе опорного элемента) — O(n²). Для связных списков QuickSort часто реализуют путем обмена значений в узлах (data), а не перестановкой самих указателей, что делает код более понятным и безопасным.

## Полный код решения

```cpp
#include <iostream>
#include <stdexcept>
#include <algorithm> // для std::swap
#include <locale.h>

using namespace std;

// ==================== 1. ОДНОСВЯЗНЫЙ СПИСОК ====================
template <typename T>
class SinglyLinkedList {
private:
    struct Node {
        T data;
        Node* next;
        Node(const T& value) : data(value), next(nullptr) {}
    };
    Node* head;
    Node* tail;
    int count;

public:
    SinglyLinkedList() : head(nullptr), tail(nullptr), count(0) {}
    ~SinglyLinkedList() { clear(); }

    void push_back(const T& value) {
        Node* newNode = new Node(value);
        if (head == nullptr) head = tail = newNode;
        else { tail->next = newNode; tail = newNode; }
        count++;
    }

    void print() const {
        Node* current = head;
        cout << "[";
        while (current != nullptr) {
            cout << current->data;
            if (current->next != nullptr) cout << ", ";
            current = current->next;
        }
        cout << "]";
    }

    void clear() {
        while (head != nullptr) {
            Node* temp = head;
            head = head->next;
            delete temp;
        }
        tail = nullptr; count = 0;
    }
    int size() const { return count; }
};


// ==================== 2. ДВУСВЯЗНЫЙ СПИСОК ====================
template <typename T>
class DoublyLinkedList {
private:
    struct DNode {
        T data;
        DNode* prev;
        DNode* next;
        DNode(const T& value) : data(value), prev(nullptr), next(nullptr) {}
    };
    DNode* head;
    DNode* tail;
    int count;

    // --- Вспомогательный метод для QuickSort ---
    // Разделяет список относительно опорного элемента (pivot)
    DNode* partition(DNode* low, DNode* high) {
        T pivot = high->data; // Опорный элемент - последний в диапазоне
        DNode* i = low->prev; // Указатель на последний элемент, который <= pivot

        for (DNode* j = low; j != high; j = j->next) {
            if (j->data <= pivot) {
                // Если i == nullptr, значит это первый элемент, который <= pivot
                i = (i == nullptr) ? low : i->next;
                swap(i->data, j->data); // Меняем местами данные
            }
        }
        i = (i == nullptr) ? low : i->next;
        swap(i->data, high->data); // Ставим pivot на свое законное место
        return i;
    }

    // --- Рекурсивный QuickSort ---
    void quickSort(DNode* low, DNode* high) {
        if (low != nullptr && high != nullptr && low != high && low != high->next) {
            DNode* pivot = partition(low, high);
            quickSort(low, pivot->prev);   // Сортируем левую часть
            quickSort(pivot->next, high);  // Сортируем правую часть
        }
    }

public:
    DoublyLinkedList() : head(nullptr), tail(nullptr), count(0) {}
    ~DoublyLinkedList() { clear(); }

    void push_back(const T& value) {
        DNode* newNode = new DNode(value);
        if (tail == nullptr) {
            head = tail = newNode;
        }
        else {
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }
        count++;
    }

    // ==================== МЕТОД sort() (ВАРИАНТ 4) ====================
    // Публичный метод для запуска быстрой сортировки
    void sort() {
        if (head == nullptr || head->next == nullptr) return; // Если 0 или 1 элемент - уже отсортировано
        quickSort(head, tail);
    }

    void print() const {
        DNode* current = head;
        cout << "[";
        while (current != nullptr) {
            cout << current->data;
            if (current->next != nullptr) cout << ", ";
            current = current->next;
        }
        cout << "]";
    }

    void printReverse() const {
        DNode* current = tail;
        cout << "[";
        while (current != nullptr) {
            cout << current->data;
            if (current->prev != nullptr) cout << ", ";
            current = current->prev;
        }
        cout << "]";
    }

    void clear() {
        while (head != nullptr) {
            DNode* temp = head;
            head = head->next;
            delete temp;
        }
        tail = nullptr; count = 0;
    }
    int size() const { return count; }
};

// ==================== ГЛАВНАЯ ФУНКЦИЯ ====================
int main() {
    setlocale(LC_ALL, "ru");

    cout << "=== 1. Демонстрация односвязного списка ===" << endl;
    SinglyLinkedList<int> sList;
    sList.push_back(10);
    sList.push_back(20);
    sList.push_back(30);
    cout << "Односвязный список: "; sList.print(); cout << endl << endl;

    cout << "=== 2. Демонстрация двусвязного списка и метода sort() ===" << endl;
    DoublyLinkedList<int> dList;
    // Добавляем элементы вразнобой
    dList.push_back(40);
    dList.push_back(10);
    dList.push_back(50);
    dList.push_back(20);
    dList.push_back(30);

    cout << "Исходный (неотсортированный) список: "; dList.print(); cout << endl;
    cout << "Исходный в обратном порядке:         "; dList.printReverse(); cout << endl;

    // Вызов реализованной быстрой сортировки
    dList.sort();

    cout << "После вызова sort() (QuickSort):     "; dList.print(); cout << endl;
    cout << "Проверка (обратный порядок):         "; dList.printReverse(); cout << endl;

    return 0;
}
```

**Контрольные вопросы**

1.Чем связный список отличается от динамического массива?
Список не хранит элементы непрерывно (нет доступа по индексу за O(1)), но вставка/удаление в начало или середину происходит за O(1), если у нас есть указатель на место вставки.

2.Какие операции в односвязном списке выполняются за O(1)?
Добавление в начало (push_front), удаление из начала (pop_front), добавление в конец (если хранится tail).

3.Почему удаление из конца односвязного списка требует O(n)?
Чтобы удалить последний элемент, нужно обнулить указатель next у предпоследнего элемента. Так как ссылки «назад» нет, нужно пройти от начала до предпоследнего узла.

4.Какие преимущества даёт хранение указателя tail в односвязном списке?
Позволяет добавлять элементы в конец (push_back) за O(1), а не за O(n).

5.Чем двусвязный список отличается от односвязного?
Каждый узел двусвязного списка содержит дополнительный указатель prev на предыдущий узел.

6.Какие операции в двусвязном списке выполняются быстрее, чем в односвязном?
Удаление из конца (pop_back) и обход в обратном порядке.

7.Что такое «голова» (head) и «хвост» (tail) списка?
Указатели на первый и последний элементы списка соответственно.

8.Как удалить узел из середины односвязного списка?
Найти узел перед удаляемым, сохранить указатель на следующий за удаляемым, перенаправить next предыдущего и сделать delete для удаляемого.

9.Как удалить узел из середины двусвязного списка? Почему это проще?
Проще, так как можно обратиться к node->prev и node->next напрямую, не ища предыдущий узел с самого начала.

10.Что произойдёт, если забыть обновить tail при удалении?
Указатель tail будет указывать на уже освобожденную память (dangling pointer), что приведет к ошибке при следующем добавлении.

11.Как реализовать реверс односвязного списка?
Пройти по списку, меняя указатели next на противоположные с помощью трех указателей: prev, current, next.

12.Как обнаружить цикл в связном списке?
Метод «черепахи и зайца»: два указателя движутся с разной скоростью (один на 1 шаг, другой на 2). Если они встретятся — есть цикл.

13.В каких случаях стоит использовать список вместо массива?
При частых вставках и удалениях в середине структуры, когда неизвестен итоговый размер, и не требуется быстрый доступ по индексу.

14.Какая дополнительная память требуется для каждого узла списка?
Односвязный: 1 указатель. Двусвязный: 2 указателя (на следующий и предыдущий).

15.Почему доступ по индексу в списке имеет сложность O(n)?
Из-за отсутствия непрерывности в памяти. Чтобы найти i-й элемент, нужно последовательно пройти от начала все предыдущие элементы.
